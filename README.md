# Doğru mu Uydurma mı? · True or Made Up?

Şaşırtıcı gerçekleri yaygın efsanelerden ayır

Her cümlenin doğru mu yoksa uydurma mı olduğunu seç. Yanıttan sonra gelen kısa açıklamayla gerçeği öğren.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Bilgi Yarışması merkez uygulamasının oyunu; ortak motor: [bilgi-motoru](https://github.com/taktemurr-ops/bilgi-motoru).
